# Stock Average｜iPhone 股票攤平計算器

## 目前版本
- 手動輸入股票代號、市場、股價、持股數與平均成本
- 支援美股 USD、台股 TWD（股數以「股」為單位）
- 滑桿與數字欄位試算加碼後均價
- 目標均價反推加碼股數
- 逐筆買進／賣出紀錄，採移動加權平均法
- 本機保存、JSON 匯出／匯入備份
- PWA，可部署到 HTTPS 網站後加入 iPhone 主畫面

## iPhone 安裝方式
1. 將整個資料夾部署到支援 HTTPS 的靜態網站空間（例如 GitHub Pages、Cloudflare Pages 或 Netlify）。
2. 用 iPhone Safari 開啟部署後網址。
3. 點「分享」→「加入主畫面」。
4. 之後從主畫面圖示開啟。

## 重要限制
- 這個版本不連接行情 API，股價必須手動輸入。
- 資料保存在該裝置的瀏覽器本機儲存空間，不會自動跨裝置同步。
- 請定期匯出 JSON 備份；清除 Safari 網站資料可能刪除資料。
- 逐筆紀錄使用移動加權平均法；手動成本與逐筆模式可切換。若逐筆模式有紀錄，計算器會優先依交易紀錄計算持倉。
- 試算不含稅費、手續費、匯率及滑價；賣出成本按移動平均成本沖減。
- 本工具只做數學試算，不構成投資建議。
